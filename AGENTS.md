# Design work

For UI design, customer journeys, frontend changes, or visual reviews, use the
`design-with-evidence` skill in `.agents/skills/design-with-evidence/SKILL.md`.
Read `Daytona-Car-Rentals/docs/design/daytona-guide.md` for Daytona decisions and
source locations. Load detailed references only when relevant.

The application is in `Daytona-Car-Rentals/`. Preserve the current branch's work
and the separate presentation worktree. A review or guidance task does not
implicitly authorize application edits, a redesign, deployment, or hosted changes.
Keep proposed design changes separate from owner-approved decisions.
