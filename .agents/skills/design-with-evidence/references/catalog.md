## Add only useful evidence

For a reference actually used, record: exact deep URL; date; access method;
pattern/state observed; what to adapt and why; what not to copy; accessibility
source; limitations. Label inaccessible or login-gated material explicitly.
Do not infer that a site's popularity proves usability. Routine Daytona changes
should start with the approved guide and current rendered components instead.
